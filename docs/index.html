Honest scope

What ships—and what does not.

Working today

  • Seeded web PWA and Tauri desktop shell
  • Markdown editing, search, goals, backlinks, modes
  • File/index adapters and conflict-safe primitives
  • Export and publishing interfaces with deterministic adapters
  • Accessibility and performance test gates

Still a separate track

  • Mobile is a placeholder shell, not a finished mobile release
  • Slate Sync is an interface and local merge model—not a hosted service
  • Publishing adapters are not hosted integrations
  • The web demo uses seeded browser state, not your disk
  • No multiplayer, plugin marketplace, or proprietary block format
FAQ

Know where your words live.

Where are my files?

In local folders you choose. Each sheet is a Markdown file. Slate’s SQLite full-text index is a disposable cache that can be rebuilt from those files.

Is there a subscription?

No. The local core and source are free. A future hosted Slate Sync service is a separate, optional track and is not part of this demo.

Does it run on Windows and Linux?

Yes. The codebase targets a Tauri desktop shell for Windows, Linux, and macOS, plus the browser PWA. This site’s live demo is the PWA.

Does the web demo access my files?

No. It opens a seeded sample Space in browser state. Directory-handle and OPFS adapters exist in the codebase, but the public demo does not prompt for or touch your local folders.

Is sync available?

BYO-folder conflict reconciliation and sync interfaces are implemented as tested primitives. There is no hosted Slate Sync backend yet, and the website does not claim one.

Why “calm”?

Slate uses progressive disclosure: a familiar three-pane workspace, quiet Markdown, focus/typewriter modes, and a command palette instead of a wall of plugins and settings.
