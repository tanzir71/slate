# Landing-page comparison sources

Checked **18 November 2026**. Compare the current, built-in writing products; browser publishing is distinct from a browser editor. Refresh the table and this date before each public release. Prices, editions and platform availability can change.

| Product | Claims used on the landing page | Primary sources |
| --- | --- | --- |
| Slate | Writes ordinary Markdown files in selected folders or a browser library; runs in the browser; local writing is free | Repository browser storage implementation, browser E2E suite, and `docs/browser.md` |
| Obsidian | Local Markdown files; downloadable desktop/mobile apps; free local writing | [Product](https://obsidian.md/), [downloads](https://obsidian.md/download), [pricing](https://obsidian.md/pricing) |
| Typora | File-based Markdown editor; desktop apps; one-time purchase | [Product and file management](https://typora.io/), [official store and licensing FAQ](https://store.typora.io/) |
| iA Writer | File-based Markdown editor; desktop/mobile apps; one-time purchases per platform | [Product](https://ia.net/writer), [downloads](https://ia.net/writer/download), [official pricing](https://ia.net/writer/pricing) |
| Bear | Markdown export rather than arbitrary-folder editing; free core with Pro features; public Web beta | [Markdown export](https://bear.app/faq/export-your-notes/), [product](https://bear.app/), [public Web beta and upcoming changes, 10 November 2026](https://community.bear.app/t/bear-web-is-almost-here-and-bear-pro-is-getting-a-new-price/20115) |

The landing deliberately uses pricing models instead of numerical prices, because iA Writer licenses vary by platform and Bear has an announced pricing change on 24 November 2026. The browser row describes the editing surface; it does not compare publishing, sharing or sync. Desktop/mobile labels are based on each vendor's offered downloads, not an inference about future plans.

Slate's unshipped slash blocks, prompted templates, Tidy, rules, CLI, MCP and Sync are excluded from the current feature comparison. Add them only after the corresponding implementation and release gates pass. The design handover's full table remains the target as those features ship.
