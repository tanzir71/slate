# Slate 0.2.0 — Use it today

Write in [Slate in your browser](https://tanzir71.github.io/slate/app/), close the tab, and continue with the same Markdown files tomorrow. No account or server is needed.

- Open a folder in Chrome or Edge, keep a private browser library, or explore a temporary Sample Space and keep it when ready.
- Autosave your writing, preserve conflicting edits as copies, recover interrupted drafts, and move deleted sheets to recoverable trash.
- Import files, folders or zip archives; export an entire Space with Markdown, assets and configuration intact.
- Write offline after the first visit. Updates wait for Reload and finish saving before activation.
- Find sheets, organize notebooks and tags, and use keyboard formatting. The editor remembers the selected sheet, caret, scroll and inspector preference.
- Install Slate where your browser offers installation. Launch shortcuts and file handling ask before creating or appending files.
- Read release notes and browser capabilities in About Slate. The redesigned landing links directly to the same deployed app.

Browser libraries live in the browser's private storage. Export a zip regularly; removing site data removes those private files. Files in a selected folder stay on disk. Folder editing and installed-app file handling depend on browser support.

The rest of the Slate 2.0 handover continues in small releases. Dark mode, blocks, templates, Tidy, automation, desktop installers and history/export formats come later. Opt-in encrypted Sync is last and will be free while in beta.
